# Apex オーバーレイカウンター — OBS 設定・操作ガイド

「Apexオーバーレイカウンター」を OBS に組み込む手順と、配信中の操作方法をまとめます。
ポイントは **「表示（配信に映る側）」と「操作（自分だけが触る側）」を別々に追加する**こと。
両方を **同じ URL（同一オリジン）** で OBS 内に置くと、操作パネルで押した内容がオーバーレイへ即座に反映されます。

---

## OBS で使う URL

OBS で使うのは、次の 2 つの URL です（末尾の `?view=` だけが違います）。

| 用途 | URL |
|---|---|
| 表示（オーバーレイ） | `https://john-smith07.github.io/apex-match-kill-count/?view=overlay` |
| 操作（コントロールパネル） | `https://john-smith07.github.io/apex-match-kill-count/?view=panel` |

> ⚠️ `?view=overlay` を付けないと、確認用の枠（濃い箱）や操作パネルまで一緒に表示されます。**配信に出す側は必ず `?view=overlay`** を付けてください。

---

## 手順1. オーバーレイをブラウザソースとして追加

1. 配信に使うシーンを選ぶ
2. 「ソース」パネルの **＋** →「**ブラウザ**」を追加 → 名前を付けて OK
3. プロパティで設定：
   - **URL**：`https://john-smith07.github.io/apex-match-kill-count/?view=overlay`
   - **幅**：`480` / **高さ**：`160`（あとで調整可）
   - **FPS**：`30`
   - ☑ が付いていれば外す：**「シーンがアクティブになったときにブラウザの表示を更新する」**（カウントがリセットされるのを防止）
   - **「表示されていないときにソースをシャットダウンする」** も外しておくと安定
4. OK で閉じる。背景は透過されるので、映像やフレームの上に重なります。

> 背景が黒くなる場合：プロパティ下部の「カスタム CSS」に既定で入っている
> `body { background-color: rgba(0,0,0,0); ... }` が消えていないか確認してください。

---

## 手順2. 操作パネルをカスタムブラウザドックとして追加

操作パネルは**配信画面には出さず**、OBS のドック（作業画面の一部）として開きます。ここが同期のキモです。

1. 上部メニュー **「ドック」→「カスタムブラウザドック…」**
2. 行を 1 つ追加し、
   - **ドック名**：`Apexカウンター`
   - **URL**：`https://john-smith07.github.io/apex-match-kill-count/?view=panel`
3. 「適用」→「閉じる」
4. パネルがドックとして現れます。ウィンドウ端や画面外にドラッグして、好きな位置に固定できます。

> 💡 別の Chrome タブでパネルを開くと**同期しません**（OBS の内部ブラウザとは別プロセスのため）。必ず**この方法で OBS 内に**開いてください。

---

## 手順3. 位置・サイズを整える

1. シーン上のオーバーレイを**ドラッグで移動**、四隅の**ハンドルで拡大縮小**
2. スタイルによって最適な形が変わります：
   - **Apex / カード / ブロック**：やや縦のある枠 → 幅 `480 × 高さ 160` あたり
   - **バー**：横長で薄い帯 → 幅 `560 × 高さ 90` あたり（フレームの上下ラインに沿わせやすい）
3. 余白が気になる場合は、ソースを **Alt＋ドラッグ**でトリミング

---

## 使い方

- **表示スタイル**：パネル上部の「表示スタイル」で `Apex / カード / バー / ブロック` を切替。オーバーレイに即反映されます。
- **試合数・キル数の表示 ON/OFF**：各カードの「オーバーレイに表示」スイッチ。片方だけ隠すことも可能。
- **カウント操作**：
  - `−1 / ＋1` … クイックに増減
  - **プラス／マイナス**トグルを選び、**数字キー**を押すと**その場で反映**（例：プラスで `3` を押すと +3）。複数桁も入力可（`1`→+1、続けて `2`→+12）
  - **セット**＝現在値を確定 ／ **取消**＝入力を始める前の値に戻す
  - `0に` … そのカウントを 0 にリセット
- **キーボード**（パネルにフォーカス時）：`0-9`即時入力 / `Space`±切替 / `Enter`セット / `Esc`取消 / `+ -`で±1 / `Backspace`で1桁削除。対象は**クリックで選択中のカード**。

## うまく動かないときは

| 症状 | 対処 |
|---|---|
| 背景が透過されず**濃い箱が残る** | オーバーレイの URL に **`?view=overlay`** が付いているか確認（最も多い原因）。付けると HUD だけが透過表示になります。 |
| パネルで押しても**オーバーレイが変わらない** | 表示と操作の URL が**同一オリジン**か確認（同じ `https://john-smith07.github.io/apex-match-kill-count/` で `?view=` だけが違う）。パネルは**OBS のカスタムブラウザドック**で開く。 |
| 背景が**黒く**なる | ブラウザソースのカスタム CSS（透過指定）が残っているか確認。 |
| 配信再開後に**数値がリセット**される | 手順 1 の「更新」「シャットダウン」チェックを外す。 |
| **フォントが違う**／表示が崩れる | ネット接続を確認。オフライン時はシステムフォントで代替表示されます。 |

---

## ファイルを更新したとき

オーバーレイの HTML を差し替えたら、OBS 側で反映します。オーバーレイのブラウザソースを**右クリック →「更新」**、またはプロパティを開いて「OK」で再読み込みされます。キャッシュが残る場合はプロパティ内の「現在のページのキャッシュを更新」を押してください。
